# Paper result tables

`route_finding.csv` contains the success-at-budget values used in the main
route-finding table and figure.

`ursa_metrics.csv` contains raw target counts and aggregate official URSA
metrics for every final P* single-step-model configuration included in the
Supporting Information.

Published baseline rows remain under the licenses of their source papers and
are cited in the manuscript. Per-target routes are not included because the
third-party model assets and benchmark releases are distributed separately.
